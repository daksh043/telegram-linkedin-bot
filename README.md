# OutreachAI

AI-powered Telegram assistant for company research, personalized student-industry outreach, and outreach tracking.

The bot drafts and organizes outreach. **You remain responsible for reviewing and sending messages externally.**

## Core flow

Find Company → Research → AI Understands Company → Personalize Message → Review → Send Manually → Mark Sent → Update Tracker → Follow-up → Response → Meeting/Opportunity → Analytics

## Setup

1. Create a virtual environment (Python 3.11+):

   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # macOS / Linux
   source .venv/bin/activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create a bot with [@BotFather](https://t.me/BotFather) on Telegram and copy the token.

4. Get a Google AI Studio (Gemini) API key from [aistudio.google.com/apikey](https://aistudio.google.com/apikey).

5. Configure credentials:

   ```bash
   cp .env.example .env
   ```

   Then fill in `GEMINI_API_KEY` and `TELEGRAM_BOT_TOKEN`.
   (To use OpenAI instead, clear `AI_BASE_URL`, set `AI_MODEL` to an OpenAI
   model, and put your key in `OPENAI_API_KEY`.)

6. **Allowlist yourself.** Send any message to your bot once — it replies with
   your Telegram ID (the bot refuses everyone until configured). Put that ID in
   `TELEGRAM_ALLOWED_USER_IDS` in `.env` and restart.

7. Run:

   ```bash
   python -m app.bot
   ```

## Usage

| Command | Purpose |
|---|---|
| `/company` | Research a company (LinkedIn/website URL or pasted info) |
| `/person` | Add a contact at the current company |
| `/companies`, `/company_info <id>` | Browse saved companies |
| `/email`, `/message` | Generate email / LinkedIn drafts |
| `/rewrite`, `/short`, `/formal`, `/human` | Rework the current draft |
| `/save` | Save the draft (status: Drafted) |
| `/mark_sent <id>` | Mark sent — records date and schedules follow-up |
| `/mark_replied <id> [status] [text]` | Record a response/outcome |
| `/followups` | Outreach needing follow-up |
| `/status` | Response/interest metrics |
| `/export` | Build and send the Excel tracker |
| `/settings` | Show configured profile |

Typical session: `/company` → paste a LinkedIn company URL → review the AI summary → tap **Email**/**LinkedIn** → refine with **Shorter/Formal/Human** → `/save` → send it yourself → `/mark_sent`.

## Data

- SQLite (`data/outreach.db`) is the source of truth: companies, contacts, outreach.
- Excel (`data/Outreach_Tracker.xlsx`) is generated by `/export` with sheets:
  Outreach Tracker, Contacts, Dashboard, Settings.
- Back both files up regularly.

## Security rules

- Secrets live only in `.env`; never commit, print, or send them.
- Telegram access is restricted to `TELEGRAM_ALLOWED_USER_IDS`.
- No LinkedIn scraping — only user-provided text, permitted public information,
  and public company websites.
- The AI must never invent company facts; prompts enforce this and drafts use
  only verified input.
- Review every draft before sending.
