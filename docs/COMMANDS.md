# Telegram Commands

## Basic

- `/start` — initialize the bot
- `/help` — show available commands

## Research

- `/company` — start company research
- `/person` — research a professional/contact
- `/companies` — list saved companies
- `/company_info` — show company information

## Outreach

- `/email` — generate an email draft
- `/message` — generate a LinkedIn message
- `/rewrite` — rewrite the current draft
- `/short` — create a shorter version
- `/formal` — make it more formal
- `/human` — make it more natural

## Tracking

- `/mark_sent` — mark an outreach as sent
- `/mark_replied` — mark an outreach as replied
- `/followups` — show records needing follow-up
- `/status` — show outreach metrics
- `/export` — generate/update and export Excel

## Suggested buttons

```text
[Email] [LinkedIn] [Short] [Formal]
[Human] [Rewrite] [Save] [Mark Sent]
```
